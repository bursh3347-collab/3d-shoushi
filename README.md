## 0. 这是什么 / 它的用途

核心原理只有两步：

1. **MediaPipe** 读取摄像头画面，实时追踪**每只手上的 21 个关键点**（指尖、关节、手腕等）。
2. **TouchDesigner** 把这些点的坐标转成参数，去驱动一个 **3D 物体**（教程里是一个会「故障/glitch」的立方体），让它对你的每个手势做出反应。

Claude（Claude Code）负责把「我想要的控制逻辑」从零写成 TouchDesigner 能跑的 Python 脚本。

### 能用来做什么（用途）

- **现场视觉表演 / VJ**：时装秀、新品发布会、演唱会、夜店现场用手实时操控画面。

## 1. 复现步骤（全量）

### Step 1 — 下载 TouchDesigner
- 官网：https://derivative.ca
- 安装后选择 **Non-Commercial（免费非商业）** 许可即可上手。

### Step 2 — 装 MediaPipe 插件
- 插件地址：https://github.com/torinmb/mediapipe-touchdesigner
- 下载后**把文件拖进 TouchDesigner 即可，无需安装**。

### Step 3 — 开启双手追踪
- 点击 `hand_tracking` 节点，把 **numHands 设为 2**，实时追踪双手。

### Step 4 — 用 Claude Code 生成脚本
- 在项目文件夹里打开 Claude Code，粘贴 [`PROMPT.md`](./PROMPT.md) 里的提示词。
- Claude 会输出一个带注释的 **Python DAT 脚本**（本仓库已附参考实现：[`scripts/glitch_cube.py`](./scripts/glitch_cube.py)）。

### Step 5 — 接线
- 新建一个 **Python DAT** 节点，把脚本粘进去，把 **MediaPipe 的输出**连接到这个节点。

### Step 6 — 播放
- 按 **Play**，立方体出现，跟着你的双手动。

### Step 7 — 换物体
- 之后可以把立方体换成**任何其他 3D 物体**，所有手势控制照常工作。

## 2. 手势控制映射（教程设定）

| 手势 | 效果 |
|---|---|
| 双手中点位置 | 立方体在屏幕上移动（平移） |
| 双手之间的角度 | 立方体绕 X / Y 轴旋转 |
| 双手之间的距离 | 放大 / 缩小 |
| 左手捏合 | 增加噪声失真（glitch 强度） |
| 右手捏合 | 循环切换颜色 |
| 快速移动 | 触发故障闪烁 |
| 双拳同时握住 | 冻结画面（方便截图） |
